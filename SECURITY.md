# Security Policy

## Scope

This project contains educational materials and safe lab examples. It is not an authorization to test any external system.

## Do not report secrets publicly

Do not commit or publish:

- API keys
- Passwords
- Access tokens
- Private keys
- Personal information
- Protected health information
- Confidential client information
- Production logs or datasets

If you discover an accidental exposure, stop using the material, avoid reproducing the secret, and contact the repository owner through GitHub with a private report.

## AI security labs

Only test systems, prompts, datasets, or applications supplied for the lab or explicitly authorized by the owner. Do not scan, exploit, exfiltrate, or disrupt external systems.

## Responsible reporting

For a suspected vulnerability in project code or lab infrastructure, provide:

- Affected file, workflow, or component
- Reproduction steps using safe test data
- Potential impact
- Suggested mitigation
- Any evidence that does not contain secrets or personal information

Security reports will be triaged before public disclosure.
