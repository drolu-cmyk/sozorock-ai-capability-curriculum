## Source-use rules

- Prefer primary sources and stable canonical pages.
- Do not copy large passages; summarize in original language.
- Record third-party licenses for datasets, images, screenshots, and code.
- Remove obsolete links or mark them as historical.
- A framework name in a lesson is not a claim of endorsement.
