# Open-Source Model

## Why the curriculum is public

The project is intended to make practical AI, cybersecurity, and GRC learning more accessible to nonprofit organizations, educators, community organizations, small businesses, public systems, and emerging talent.

## What is open

The public repository may contain:

- Learner missions
- Trainer facilitation guides
- Safe examples
- Templates
- Rubrics
- Policies
- Documentation
- Non-sensitive lab code

## What must remain outside this repository

Do not publish:

- Learner submissions
- Personal or confidential information
- Secrets and credentials
- Private trainer notes
- Unreleased examination banks
- Authorized penetration-test findings
- Third-party content without redistribution rights

## Reuse

You may adapt the curriculum under CC BY 4.0 when you provide attribution, link to the license, and identify changes. Code is available under MIT as described in LICENSE.

## Quality expectation

Open does not mean unreviewed. Contributions should preserve plain language, accessibility, safety, evidence-based assessment, and responsible AI practice.
