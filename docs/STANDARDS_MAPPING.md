# Standards and framework mapping

This curriculum teaches applied capability and evidence production. It does not certify a learner or an organization against a framework.

## Core mappings

| Curriculum capability | NIST AI RMF | NIST CSF 2.0 | ISO/IEC 42001 | Security reference |
|---|---|---|---|---|
| Frame purpose, context, and impact | Govern, Map | Govern, Identify | Context, leadership, planning | NICE work-role language |
| Build a controlled workflow | Manage | Protect | Operation | Secure design practice |
| Evaluate quality and reliability | Measure | Identify, Detect | Performance evaluation | Test and measurement |
| Threat-model AI behavior | Map, Measure, Manage | Identify, Protect, Detect | Risk treatment | OWASP LLM Top 10, MITRE ATLAS |
| Govern lifecycle and accountability | Govern, Map, Manage | Govern, Identify, Respond | AIMS requirements | Organizational oversight |
| Implement controls and evidence | Govern, Manage | Protect, Detect, Respond, Recover | Improvement and documented information | GRC control testing |
| Explain decisions and residual risk | Govern, Measure | Govern, Respond | Communication and review | Executive communication |

## How to use the mapping

- Treat the mapping as a learning aid, not an audit opinion.
- Record the framework version and access date in every learner evidence package.
- Keep legal or regulatory interpretation in the trainer's jurisdiction-specific appendix.
- Do not claim ISO certification, NIST certification, or regulatory compliance from course completion.
- Recheck external references during each release cycle.
