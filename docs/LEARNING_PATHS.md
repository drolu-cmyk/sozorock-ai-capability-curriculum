# Five learning paths

The program can be delivered as one sequence or as five connected pathways.

## 1. AI capability and use-case framing

For learners who need to identify useful, safe opportunities.

Core evidence: use-case canvas, stakeholder map, success measure, risk boundary.

Modules: M00–M01.

## 2. Workflow and agent building

For learners who want to build repeatable AI-enabled work.

Core evidence: interaction specification, workflow specification, action map, approval design.

Modules: M02, M04–M05.

## 3. Data, evaluation, and reliability

For learners who need trustworthy outputs.

Core evidence: source register, retrieval test set, evaluation report, monitoring plan.

Modules: M03 and M06.

## 4. AI cybersecurity and secure design

For cybersecurity learners, builders, and technical reviewers.

Core evidence: threat model, safe attack log, control plan, incident playbook.

Modules: M07–M08.

## 5. AI governance, risk, and GRC

For GRC, audit, compliance, risk, and executive stakeholders.

Core evidence: AI inventory, risk register, control matrix, evidence plan, executive brief.

Modules: M09–M12.

All pathways use the same safety policy and portfolio evidence model.
