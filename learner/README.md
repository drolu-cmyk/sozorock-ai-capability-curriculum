# Learner Guide

## Start here

1. Read the lab safety policy.
2. Complete the orientation module.
3. Choose a low-risk workflow for your capstone.
4. Complete each mission in order.
5. Save evidence in your cohort workspace.
6. Ask for help only after completing the troubleshooting checklist.
7. Submit the required artifact before moving forward.

## How to work

Do not aim for a perfect first result. The curriculum expects you to observe failure, test assumptions, improve the system, and document what changed.

## Each mission contains

- Goal
- Why it matters
- Prerequisites
- Step-by-step actions
- Checkpoints
- Troubleshooting hints
- Required submission
- Reflection
- Extension challenge

## Learner rule

Never use real personal, health, financial, employment, legal, or confidential organizational data in a lab unless the trainer has explicitly approved the data-handling plan.
