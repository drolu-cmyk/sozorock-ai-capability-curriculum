# Evidence Portfolio Rubric

## Portfolio components

- Use-case canvas
- Test set
- Evaluation report
- Threat model
- Security control plan
- AI risk register
- Control matrix
- Human-oversight plan
- Incident-response exercise
- Executive briefing

## Assessment dimensions

| Dimension | Weight |
|---|---:|
| Problem and stakeholder understanding | 15% |
| Working system or workflow | 20% |
| Evaluation quality | 15% |
| Security and threat analysis | 20% |
| Governance and control evidence | 20% |
| Communication and reflection | 10% |

A successful portfolio must demonstrate both capability and responsible judgment.
