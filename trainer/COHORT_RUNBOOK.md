# Trainer cohort runbook

## Before the cohort

- Confirm the module sequence and learning outcomes.
- Test every lab using the same access level learners will have.
- Prepare synthetic data and a manual fallback.
- Confirm the approved workspace and data rules.
- Review the safety policy and escalation path.
- Prepare accessibility accommodations.
- Explain that course completion is not a professional certification.

## At the start of each session

- State the capability being practiced.
- State what must not be entered or tested.
- Show the evidence learners will submit.
- Confirm the tool, version, date, and account boundary.
- Demonstrate the first checkpoint without completing the learner's work.

## During the lab

Use questions before answers:

- What did you expect to happen?
- What evidence supports that conclusion?
- What failed or remained uncertain?
- What is the safest next test?
- What should a human approve?

Stop the activity if a learner is about to use real sensitive data, test an unauthorized system, disclose a secret, or trigger an irreversible action.

## Close the session

- Collect evidence through the approved channel.
- Record timing and friction in the pilot log.
- Run the debrief.
- Give rubric-based feedback.
- Record any safety or accessibility issue without exposing personal data.
