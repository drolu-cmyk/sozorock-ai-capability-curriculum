# Trainer Guide

## Trainer responsibility

The trainer creates the conditions for safe, evidence-based practice. The trainer should demonstrate briefly, let learners work, coach with questions, and assess the submitted evidence.

## Standard session rhythm

- Briefing: establish context and success criteria
- Demonstration: show the smallest useful example
- Lab: learners complete the mission
- Break: learners test failure modes
- Review: peers or trainer examine evidence
- Debrief: connect the lab to real work
- Assessment: record the result and next action

## Coaching rule

Do not take over the learner's keyboard or complete the mission for them. Use progressive hints:

1. Ask what the learner expected.
2. Ask what evidence is missing.
3. Point to the relevant step.
4. Show a small example.
5. Demonstrate only if the learner has attempted the troubleshooting checklist.

## Trainer preparation

Before each session, verify:

- The lab environment works.
- Test data contains no sensitive information.
- The expected output and rubric are available.
- The learner submission path is ready.
- The trainer knows which actions require human approval.
- The session has an extension task for early finishers.
