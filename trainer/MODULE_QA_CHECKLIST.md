# Module QA checklist

Use this before changing a module status to ready-for-pilot.

- [ ] Module has a clear capability outcome.
- [ ] Prerequisites are accurate.
- [ ] Learner mission is step-by-step.
- [ ] Trainer guide includes preparation, timing, demonstration, coaching, safety, and debrief.
- [ ] Lab can run with approved synthetic or public data.
- [ ] Core path works without paid tools.
- [ ] Build path is optional and reproducible.
- [ ] Stretch path adds depth rather than hidden requirements.
- [ ] Evidence artifacts are named.
- [ ] Rubric totals 100 points and has a pass rule.
- [ ] Critical safety failures are explicit.
- [ ] Failure cases and fallback behavior are tested.
- [ ] Local links and manifest validation pass.
- [ ] One trainer and one learner have completed a pilot.
- [ ] Changelog and version impact are recorded.
