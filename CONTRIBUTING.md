# Contributing

Thank you for helping improve the SozoRock AI Capability Curriculum.

## Before contributing

Read:

- CODE_OF_CONDUCT.md
- SECURITY.md
- policies/lab-safety.md
- NOTICE.md
- docs/QUALITY_ASSURANCE.md

## Contribution types

- Curriculum content
- Learner instructions
- Trainer facilitation
- Lab design
- Evaluation and assessment
- AI security and GRC guidance
- Accessibility and plain-language improvements
- Documentation and project tooling

## Licensing contributions

By contributing, you agree that:

- Code, scripts, and configuration may be distributed under the MIT License.
- Curriculum text, guides, templates, rubrics, and educational content may be distributed under CC BY 4.0.
- You have the right to contribute the material.
- You have identified or removed third-party material that cannot be redistributed.

## Curriculum change checklist

Every change should identify:

- The learner capability affected
- The module affected
- The evidence learners should produce
- The safety or GRC implications
- The version impact
- Any external source or license
- The pilot or validation evidence

## Module quality gate

A module is ready for pilot review only when it has:

- Learner mission
- Trainer guide
- Lab setup
- Step-by-step checkpoints
- Required submission
- Rubric
- Debrief
- Extension challenge
- Versioned manifest
- Safety review
- Accessibility consideration
- Tool or manual fallback

## Pull requests

Keep pull requests focused. Include:

- Summary of the change
- Files changed
- Testing or pilot evidence
- Safety and licensing review
- Follow-up work

Use a feature branch. Do not commit secrets, personal data, or learner submissions. Run the repository validation scripts before requesting review.
