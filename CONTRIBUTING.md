# Contributing

## Curriculum changes

Every change should identify:

- The learner capability affected
- The module affected
- The evidence learners should produce
- The safety or GRC implications
- The version impact

## Module quality gate

A module is ready for release only when it has:

- Learner mission
- Trainer guide
- Lab setup
- Checkpoints
- Submission requirements
- Rubric
- Debrief
- Extension challenge
- Safety review

## Branch naming

Use:

- codex/ for implementation work
- pilot/ for cohort experiments
- release/ for release preparation

## Review

Changes should be reviewed for clarity, accessibility, technical accuracy, safety, and alignment with the curriculum map.
