# SozoRock AI Capability Curriculum

A hands-on, continuously updated learning system for applied AI, cybersecurity, and AI governance, risk, and compliance.

## Learning promise

Learners will learn to:

1. Frame a useful AI use case.
2. Build and test an AI workflow.
3. Evaluate accuracy, reliability, safety, cost, and human impact.
4. Threat-model and secure AI-enabled systems.
5. Govern AI through documented risk, controls, oversight, and monitoring.
6. Explain decisions to users, managers, and community stakeholders.

## Curriculum model

Every mission follows:

Understand → Observe → Build → Break → Improve → Document → Explain

The program is designed around one progressive capstone. Each module adds a new capability and a new evidence artifact.

## Repository map

- learner/ — learner orientation and navigation
- trainer/ — facilitation standards and trainer operations
- modules/ — lessons, labs, rubrics, and module manifests
- lab-kit/ — safe starter projects, synthetic data, and test cases
- templates/ — reusable AI, security, and GRC artifacts
- assessments/ — module and portfolio assessment rules
- policies/ — lab safety, data handling, and contribution rules

## Safety

Never place API keys, credentials, personal information, protected health information, confidential client material, or production secrets in this repository or its labs. Use synthetic or de-identified data.

## Current release

Initial curriculum structure with Module 01 as the first complete pilot mission. Remaining modules are scaffolded and will be developed using the same learner/trainer/lab pattern.
