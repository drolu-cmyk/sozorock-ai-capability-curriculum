A public, hands-on curriculum for learning applied AI, cybersecurity, and AI governance, risk, and compliance.

The project is designed for learners, trainers, nonprofit organizations, community organizations, public systems, educators, employers, and funders that want practical AI capability without becoming dependent on a single tool or vendor.

## Learning promise

Learners will learn to:

1. Frame a useful AI use case.
2. Build and test an AI workflow.
3. Evaluate accuracy, reliability, safety, cost, and human impact.
4. Threat-model and secure AI-enabled systems.
5. Govern AI through documented risk, controls, oversight, and monitoring.
6. Explain decisions to users, managers, and community stakeholders.

## Curriculum model

Every mission follows:

**Understand → Observe → Build → Break → Improve → Document → Explain**

The program is built around one progressive capstone. Each module adds a capability and a new evidence artifact.

## Safety

Never place API keys, credentials, personal information, protected health information, confidential client material, or production secrets in this repository or its labs. Use synthetic, public, or de-identified data.

Read [policies/lab-safety.md](policies/lab-safety.md) and [SECURITY.md](SECURITY.md) before contributing.

## Participate
