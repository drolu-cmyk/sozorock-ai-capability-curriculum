# Module [number] — [title]

## Manifest

Create a manifest.yml containing the module ID, version, status, duration, prerequisites, outcomes, deliverables, frameworks, and safety boundaries.

## Learner mission

The learner mission must state:

- Mission goal
- Why it matters
- Time estimate
- Prerequisites
- Safety boundary
- Step-by-step actions
- Checkpoints
- Required submission
- Reflection
- Extension challenge

## Trainer guide

The trainer guide must state:

- Trainer objective
- Preparation checklist
- Session timing
- Demonstration guidance
- Coaching prompts
- Common failure modes
- Safety escalation
- Debrief questions
- Assessment instructions

## Rubric

Use observable criteria with a scoring method, a pass rule, and explicit critical safety failures.

## Debrief

Connect the lab experience to real work, affected people, organizational risk, and the next module.

## Lab requirements

The lab must identify:

- Starter files
- Approved data
- Tools or environment
- Reset procedure
- Test cases
- Evidence to preserve
- Extension challenge
