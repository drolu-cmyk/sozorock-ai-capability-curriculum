# Module 02 Rubric

| Criterion | Points |
|---|---:|
| Testable task and interaction specification | 20 |
| Quality and coverage of five-case test set | 20 |
| Baseline versus revised comparison | 20 |
| Failure and uncertainty analysis | 15 |
| Human-review and out-of-scope boundaries | 15 |
| Version log and reflection | 10 |
| **Total** | **100** |

## Pass rule

- 70 points or higher
- All five test cases preserved
- No critical safety violation
- Human-review boundary is explicit

## Critical safety failures

- Treating an unverified model output as authoritative
- Using prohibited data
- Granting an unauthorized external action
- Attempting to bypass an access or safety control
