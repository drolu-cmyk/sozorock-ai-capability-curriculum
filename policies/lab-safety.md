# Lab Safety and Data Handling

1. Use synthetic, public, or de-identified data only.
2. Never commit API keys, passwords, tokens, certificates, or private keys.
3. Never upload protected health information, financial information, or confidential client material.
4. Never test a system without authorization.
5. Do not allow an AI system to send, delete, purchase, publish, or modify external records without human approval.
6. Record model, prompt, data, tool, and version assumptions.
7. Report accidental exposure immediately to the trainer.
8. Stop a lab when a result could cause material harm.
