# Lab Kit

## Purpose

The lab kit contains safe materials for hands-on learning.

## Required contents

- Starter project
- Synthetic or public dataset
- Test cases
- Evaluation worksheet
- Reset instructions
- Expected evidence
- Extension challenge

## Lab rules

- No secrets
- No real personal or protected data
- No unauthorized testing
- No irreversible external actions
- Human approval for consequential actions
- Record assumptions and limitations
