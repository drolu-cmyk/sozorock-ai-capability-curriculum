Use fictional data for every public lab. These examples are intentionally incomplete and must not be treated as real records.

## Use rules

- Keep the IDs fictional.
- Do not add names, emails, addresses, health details, account numbers, or real case narratives.
- When testing high-impact decisions, use the dataset only to practice review boundaries and escalation.
- Record when a result is unknown instead of inventing a fact.
